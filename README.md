# MNSIT-Dataset-using-MLP

This is program that used MLP ( multiple layer perceptron ) to solve MNIST data set in the local gpu using numpy .
test percentage accuracy achieved = 98.32%
the program uses relu to activate the output of each layer and softmax to activate the final output of outut layer , which is then compared with one hot encoded labels of training set .
     input_size=784,
     hidden_size=256,
     output_size=10,
     lr=0.45
